VERCEL FRONTEND DEPLOYMENT
==========================
1. Deploy this frontend folder as a Vercel project (Framework Preset: Other).
2. Before deploying, edit config.js and replace the example URL with your real Render Java backend URL.
3. Push the contents of this frontend folder to a GitHub repository, or set Vercel Root Directory to frontend if uploading the whole project.
4. Deploy. The frontend calls the Java API hosted on Render.
